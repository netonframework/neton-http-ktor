# neton-http-ktor

Independent, optional compatibility/comparison adapter for Neton.
It does not replace the built-in default engine unless explicitly selected.
See [MIGRATION.md](MIGRATION.md) for the extraction baseline, dependencies and tests.

独立的可选兼容/对比适配器，不属于 Neton 核心发布门禁或 BOM。
Neton 默认使用自研 Kotlin/Native 栈，不需要依赖本仓库。
